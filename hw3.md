# Чек-лист проверок выбора ингредиентов пиццы

## Условия проверки

Открыт экран выбора ингредиентов базовой пиццы. Проверки выполняются для количества выбранных ингредиентов 0, 1, 4 и 5, с попытками добавить повторную порцию и шестой ингредиент. Пункты для отдельного ингредиента проверяются для каждого из шести доступных ингредиентов.

## Доступные ингредиенты и цены

- [ ] В списке доступны ровно шесть ингредиентов: Пепперони, Ветчина, Грибы, Лук, Оливки и Бекон.
- [ ] Цена одной порции Пепперони — 60 руб.
- [ ] Цена одной порции Ветчины — 70 руб.
- [ ] Цена одной порции Грибов — 50 руб.
- [ ] Цена одной порции Лука — 30 руб.
- [ ] Цена одной порции Оливок — 40 руб.
- [ ] Цена одной порции Бекона — 80 руб.

## Отсутствие ингредиентов

- [ ] При отсутствии выбранных ингредиентов отображается нотификация с точным текстом: «Необходимо добавить хотя бы один ингредиент».
- [ ] При отсутствии выбранных ингредиентов кнопка удаления заблокирована; если кнопки отдельные для каждого ингредиента, заблокированы все кнопки удаления.
- [ ] Нажатие на заблокированную кнопку удаления не изменяет состав пиццы и не приводит к ошибке приложения.
- [ ] При отсутствии выбранных ингредиентов доступны кнопки добавления всех шести ингредиентов.

## Добавление ингредиентов

- [ ] Добавление первого ингредиента в пустой состав добавляет ровно одну порцию выбранного ингредиента.
- [ ] После добавления ингредиента кнопка добавления этого же ингредиента блокируется.
- [ ] Попытка повторного добавления выбранного ингредиента не увеличивает количество его порций и не создаёт дубликат.
- [ ] При выборе от одного до четырёх ингредиентов кнопки добавления остальных, ещё не выбранных ингредиентов доступны.
- [ ] Последовательное добавление разных ингредиентов позволяет получить состав из двух, трёх, четырёх и пяти ингредиентов; каждый присутствует в одной порции.
- [ ] Добавление пятого ингредиента при четырёх выбранных проходит успешно.
- [ ] После выбора пяти ингредиентов заблокированы все кнопки добавления, включая кнопку шестого, ещё не выбранного ингредиента.
- [ ] Попытка добавить шестой ингредиент не меняет состав: остаются пять выбранных ингредиентов.
- [ ] Ограничение в пять ингредиентов действует независимо от состава: проверить все шесть вариантов набора из пяти ингредиентов.
- [ ] Быстрые повторные нажатия на добавление одного ингредиента не добавляют больше одной порции.
- [ ] При четырёх выбранных ингредиентах быстрые нажатия на добавление двух оставшихся не позволяют превысить лимит в пять ингредиентов.

## Удаление ингредиентов

- [ ] При двух–пяти выбранных ингредиентах доступно удаление любого из них.
- [ ] Удаление выбранного ингредиента убирает только его порцию; остальные ингредиенты сохраняются.
- [ ] После удаления ингредиента его кнопка добавления становится доступной.
- [ ] После удаления одного ингредиента из пяти остаются четыре; доступны кнопки добавления обоих отсутствующих ингредиентов, а кнопки добавления четырёх выбранных остаются заблокированными.
- [ ] Удалённый ингредиент можно добавить повторно в количестве одной порции.
- [ ] После замены одного ингредиента в составе из пяти на ранее не выбранный снова блокируются все кнопки добавления.
- [ ] Удаление ингредиента из состава из двух оставляет ровно один ингредиент.

## Проверки после уточнения требований

В требовании указан минимум один ингредиент, но также описано поведение при пустом составе. Необходимо уточнить, разрешено ли удалять последний ингредиент и на каком этапе контролируется минимальное количество.

- [ ] Если удаление последнего ингредиента разрешено: после удаления состав пуст, появляется указанная нотификация, кнопка удаления блокируется, кнопки добавления доступны.
- [ ] Если удаление последнего ингредиента запрещено: попытка удаления не меняет состав; состояние кнопки соответствует согласованному требованию.
- [ ] После добавления ингредиента в пустой состав предупреждение об отсутствии ингредиентов исчезает или закрывается согласно согласованным правилам показа нотификации.
- [ ] Если интерфейс показывает стоимость выбранных ингредиентов: добавление увеличивает её на цену порции, удаление уменьшает на ту же величину; Пепперони + Ветчина + Грибы + Лук + Оливки стоят 250 руб.
